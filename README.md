﻿# 战地风云 · Battlefield Ops

**把 Minecraft 变成战地式双方攻防对局。**

Minecraft **1.21.1** ｜ NeoForge **21.1.233+** ｜ 版本 **0.7.0** ｜ MIT

`mod id: battlefield_ops` ｜ `package: cn.bfops`

---

## 这是什么

一套架在原版世界之上的完整对局系统 —— 不是新维度、不新增物品方块、不改原版合成：

- **两种模式** —— 征服（抢据点、拼兵力消耗）与突破（分阶段推进，一方攻一方守）
- **游戏内地图编辑器** —— 画边界、放据点与出生点、划阶段边界与双方活动区域、配兵种、授权载具、调规则，全在 GUI 里点
- **兵种配装** —— TaCZ 武器与配件、个人物品、盔甲、Curios 配饰，服务端按兵种发放
- **载具** —— 卓越前线载具白名单部署，按武器站配置弹药发数与允许弹种，带冷却与名额
- **战术地图** —— HUD 小地图、按住 F6 看大地图与计分板、G 键标记（敌军红倒三角 / 友军蓝光晕，世界与小地图同步显示）、全图地形烘焙
- **小队部署** —— 每队 8 个 4 人小队；除出生点与据点外，还可落到**存活的队友**、**己方有空座的载具**、**本小队复活信标**；三类入口都由服务端校验，界面显示不能部署的具体原因
- **击杀反馈** —— 656 参考端的 **37 个官方预设 / 7 种图标模式 / 5 类字幕 / 177 张贴图**（F8 开列表选，F9 循环切换）+ 命中准星、爆头 / 连杀 / 助攻 / 复仇 / 救援计分
- **战场音效** —— 656 参考端的 **206 个音频全量接入**（120 个战场音效/音乐/报点 + 86 个击杀音效），背景音乐按战局状态自动切换，击杀音效跟着预设变
- **倒地救援** —— 致死伤先击倒，队友空手右键救起

> **完整使用说明见 [`使用说明.md`](./使用说明.md)** —— 20 章、全参数表、四张故障排查表。

## 快速开始

**前提：OP 权限等级 2**（`Engine` 对编辑操作强制校验 `hasPermissions(2)`）。

| 步 | 操作 |
|---|---|
| 1 | 站到地图中心，按 **F4** → 最后一个标签「地图与规则管理」 |
| 2 | 「部署」页点 **新建**，以当前位置生成草稿 |
| 3 | 「地图划线」圈出地图边界（3～64 顶点、不自交） |
| 4 | 「据点/出生」加 1～24 个据点 + 双方出生点 |
| 5 | 「规则」调兵力、时间、计分、载具冷却与名额 |
| 6 | 「兵种」配 1～16 个兵种的武器与装备 |
| 7 | 「武器/载具库」授权武器与载具，配载具武器 |
| 8 | 底部 **保存地图**，等页脚出现「地图已保存」 |
| 9 | 底部 **作战房间** → **创建本图房间** → **开始本局** |

⚠️ 三个必记规则：

1. **有房间就不能保存地图** —— 改完地图要生效，顺序永远是：改 → 保存 → 关房 → 建新房 → 开局
2. **每张地图只能有一个房间**
3. **有未保存修改时**切图、关窗、进房间都会被拦下

救援倒地队友**不是按键**：主手空手、对准倒地者按住右键 4 秒。

## 状态说明

本文档与代码同步于 **0.7.0**。代码已完成并跑通 51 组离线回归测试、3513 项检查，但下列项目**尚未在真实游戏环境中验收**，上线前请实测：

- **177 张击杀图标在游戏里的实际观感**——离线测试只能证明每条路径都指向存在的文件，证明不了 2048² 的 `valorant` 图缩到 19 px 还好看
- **37 个预设的实际观感**——滚动条的位移动画、卡牌堆叠、Valorant 光晕、荣誉徽章行都只验证了参数解析正确，没有在真实帧率下看过
- **86 个击杀音效的音量平衡**——保留了参考端每个文件自带的 0.375–1.2 音量裁剪，但没有在游戏里听过混在一起的效果
- **120 个音频是否真的响**——能证明"cue 指向存在的文件"，不能证明文件能解码、音量合适、7 段循环床不会互相打起来
- **标记手感**——12° 锥够不够宽、64 格够不够远、5 秒够不够长，都要打一局才知道
- **`MusicDirector` 在真实快照节奏下的换曲**——3 秒驻留是按"快照一秒一次"推的
- **F8 / F9 / F10 是否被整合包里其他模组抢键**
- **登车失败回滚的实际表现**——测试锁定了"失败就拒绝"这个决定，但没有真实对局证明回滚后位置与朝向原样
