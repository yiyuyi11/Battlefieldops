# 战地风云 · Battlefield Ops

**把 Minecraft 变成战地式双方攻防对局。**

Minecraft **1.21.1** ｜ NeoForge **21.1.233+** ｜ 版本 **0.6.3** ｜ MIT

`mod id: battlefield_ops` ｜ `package: cn.bfops`

---

## 这是什么

一套架在原版世界之上的完整对局系统 —— 不是新维度、不新增物品方块、不改原版合成：

- **两种模式** —— 征服（抢据点、拼兵力消耗）与突破（分阶段推进，一方攻一方守）
- **游戏内地图编辑器** —— 画边界、放据点与出生点、划阶段边界与双方活动区域、配兵种、授权载具、调规则，全在 GUI 里点
- **兵种配装** —— TaCZ 武器与配件、个人物品、盔甲、Curios 配饰，服务端按兵种发放
- **载具** —— 卓越前线载具白名单部署，按武器站配置弹药发数与允许弹种，带冷却与名额
- **战术地图** —— HUD 小地图、按住 F6 看大地图与计分板、G 键手动标记敌军、全图地形烘焙
- **击杀反馈** —— 击杀卡片、命中准星、爆头 / 连杀 / 助攻 / 复仇 / 救援计分
- **倒地救援** —— 致死伤先击倒，队友空手右键救起

> **完整使用说明见 [`使用说明.md`](./使用说明.md)** —— 20 章、全参数表、四张故障排查表。

## 安装

**客户端与服务端都可选装**：

| 客户端 | 服务端 | 结果 |
|---|---|---|
| 装 | 装 | ✅ 完整功能 |
| 不装 | 装 | ⚠️ 能连接，但不能加入战地对局；`/bf` 提示安装客户端 |
| 装 | 不装 | ⚠️ 能正常玩，但不发战地数据包 |
| 不装 | 不装 | 普通游戏 |

```powershell
# 1. 把 JAR 放进 mods/
battlefield-ops-0.6.3-neoforge-1.21.1.jar

# 2. 删掉 mods/ 里所有更旧版本的 battlefield-ops-*.jar
#    （同名模组多版本共存会导致加载失败）

# 3. 服务端同样放一份（联机开战地局时）
```

安装成功的标志：**选项 → 控制 → 按键绑定** 里出现独立的 **「战地风云」** 分类（5 个键位），且按 **F4** 能弹出主窗口。

## 快速开始

**前提：OP 权限等级 2**（`Engine` 对编辑操作强制校验 `hasPermissions(2)`）。

| 步 | 操作 |
|---|---|
| 1 | 站到地图中心，按 **F4** → 最后一个标签「地图与规则管理」 |
| 2 | 「部署」页点 **新建**，以当前位置生成草稿 |
| 3 | 「地图划线」圈出地图边界（3～64 顶点、不自交） |
| 4 | 「据点/出生」加 1～24 个据点 + 双方出生点 |
| 5 | 「规则」调兵力、时间、计分、载具冷却与名额 |
| 6 | 「兵种」配 1～16 个兵种的武器与装备 |
| 7 | 「武器/载具库」授权武器与载具，配载具武器 |
| 8 | 底部 **保存地图**，等页脚出现「地图已保存」 |
| 9 | 底部 **作战房间** → **创建本图房间** → **开始本局** |

⚠️ 三个必记规则：

1. **有房间就不能保存地图** —— 改完地图要生效，顺序永远是：改 → 保存 → 关房 → 建新房 → 开局
2. **每张地图只能有一个房间**
3. **有未保存修改时**切图、关窗、进房间都会被拦下

## 按键

| 按键 | 默认 | 作用 |
|---|---|---|
| 打开战地部署 / 编辑器 | **F4** | 主窗口（等价 `/bf`） |
| 按住查看地图与计分板 | **F6** | **按住**显示大地图 + 双方名单 |
| 标记准星前方的敌军 | **G** | 给全队标一个敌人（默认 5 秒） |
| 切换小地图位置 | `[` | 左上 → 右上 → 左下 → 右下 |
| 隐藏 / 显示小地图 | `]` | 只影响小地图 |

全部可在 **选项 → 控制 → 按键绑定 → 「战地风云」** 修改。

救援倒地队友**不是按键**：主手空手、对准倒地者按住右键 4 秒。

| 命令 | 作用 |
|---|---|
| `/bf` | 打开战地风云主窗口 |

## 数据文件位置

| 内容 | 路径 |
|---|---|
| 地图存档 | `<存档>/battlefield_ops/maps/<地图ID>.json` |
| 地形烘焙缓存 | `<存档>/battlefield_ops/terrain/<地图ID>.terrain` |
| 玩家背包备份 | `<存档>/battlefield_ops/players/<UUID>.nbt` |
| 兼容策略 | `<存档>/battlefield_ops/compat.json` |
| 客户端个人偏好 | `config/battlefield_ops-client.json` |

地图就是普通 JSON，直接复制 `maps/*.json` 即可备份。

## 构建

```powershell
# Gradle（标准 ModDevGradle）
.\gradlew build
# 产物：build\libs\battlefield-ops-0.6.3-neoforge-1.21.1.jar

# 或：离线 javac + zip，不依赖 Gradle
python .\build.py
```

> `build.gradle` 里的 `version` 是遗留字段，**真实版本号在** `src/main/resources/META-INF/neoforge.mods.toml` **和** `build.py` **里**。

## 目录结构

```
src/main/java/cn/bfops/     模组源码（~70 个类）
  Engine.java               对局引擎：房间、部署、计分、载具、地形
  Model.java                服务端配置模型 + 校验（参数范围全在这里）
  Rules.java                征服/突破的确定性结算（可离线验证）
  OpsScreen.java  等        地图编辑器界面
  Client.java               客户端 HUD 与按键
src/main/resources/         模组元数据、语言文件、图标
sim/                        离线回归测试
```

## 状态说明

本文档与代码同步于 **0.6.3**。代码已完成并跑通离线回归测试，但下列项目**尚未在真实游戏环境中验收**，上线前请实测：

- 全图地形烘焙的实际观感与耗时
- 载具武器配置是否真的按配置装填、配件编号对应的实际配件
- 个人物品 / 盔甲 / 配饰是否真的到手并穿戴、退出后是否收回
- 爆头判定阈值（身体顶部 22%）、连杀 5 秒 / 助攻 10 秒窗口的手感
- 倒地 30 秒 / 救援 4 秒的手感，趴地爬行速度
- TaCZ 枪械实射、载具摧毁、多人联机、人机模式

详见 [`使用说明.md` 第十九章](./使用说明.md#十九已知限制与未验证项)。
